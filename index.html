TeleSpeak

Modeling Early Language Acquisition with Reinforcement Learning for Large Language Models

Banff Jiang · Colin Wang · Longhao Lin · Alex Warstadt

Code References

Abstract

We investigate whether telegraphic speech, the early developmental stage where children prefer short, content-word-heavy utterances, can emerge from optimization under production constraints. Our framework uses a speaker-listener setup trained with Direct Preference Optimization (DPO). The speaker generates candidate summaries for Simple Wikipedia passages, while a RoBERTa-based listener scores semantic fidelity using BERTScore to construct preference pairs. We then add a dynamic length objective that encourages concise outputs early in training and relaxes over time.

Problem

Modern LLMs need far more data than human learners. BabyLM asks whether models can learn effectively under strict token budgets. Telegraphic speech offers a grounded hypothesis: maybe short, meaning-dense language is a rational strategy under cognitive and production limits.

Research Question

Does early one-word or two-word production emerge from high production cost rather than an innate linguistic limit? We test this by rewarding semantic success while penalizing output length.

Methods

Data

Simple Wikipedia passages (BabyLM setup), preprocessed to JSONL:

{"id": int, "source": "simplewiki", "passage": str}

Speaker

GPT-2 generates candidate summaries using seeded sampling with top-p and temperature.

Listener

RoBERTa-large computes BERTScore-based semantic preference signals.

Preference Filtering

Candidate pairs are diversity-filtered via 2-gram Jaccard similarity. Overly similar pairs are regenerated; persistent near-duplicates are discarded.

Training Objective

We combine DPO preference logits with a decaying length advantage term:

logits = beta * pref_logits + alpha(t) * len_adv
L = -log(sigmoid(logits))

pref_logits = (log pi_theta(y_c|x) - log pi_theta(y_r|x))
            - (log pi_ref(y_c|x)   - log pi_ref(y_r|x))

len_adv = (len_r - len_c) / (len_r + len_c + epsilon)
alpha(t) = alpha_0 * exp(-k * t)

This design enforces short outputs early, then gradually prioritizes semantic preference learning as training proceeds.

Preliminary Results

Early training shows stable loss behavior before full sweep experiments. We use Weights & Biases tracking to compare hyperparameter choices such as beta, decay rate, sampling settings, and diversity thresholds.

Conclusion

TeleSpeak frames telegraphic output as an optimization outcome, not just a developmental limitation. By combining DPO with length-aware curriculum pressure, this project provides a testbed for studying efficient, human-like language learning behavior under realistic data constraints.
